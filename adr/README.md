# ADR — архитектурные решения

ADR (Architecture Decision Record) — короткий документ об одном принятом
решении: в каких условиях оно принято, что решили и чем за это платим.
Эти ADR — **общие**: лучшие практики проектирования и настройки Home Assistant,
применимые к любой установке.

Правила:

- Один файл — одно решение: `NNNN-краткое-имя.md`, номера сквозные.
- Формат: Статус / Контекст / Решение / Последствия. Последствия — честные,
  включая минусы: ADR без цены решения — это реклама, а не запись решения.
- Статусы: Предложен → Принят → Устарел (заменён NNNN).
- Общее — сюда; всё, что привязано к конкретному дому, железу или адресам
  (замеры, имена сущностей, IP), — в локальные ADR своего проекта, со ссылкой
  на общий. Перед публикацией — те же проверки, что и для навыков
  (см. skills/ha-skill-authoring).
- Агенты и люди сверяются с ADR **до** проектирования и настройки; отступление
  от ADR — повод либо на новый ADR, либо на пометку «Устарел».
